# 截圖清單

README 引用了四張圖，檔名固定。放進這個資料夾就會自動顯示。

| 檔名 | 畫面 | 怎麼拍 |
|---|---|---|
| `overview.png` | 三欄主畫面 | 在一個檔案多、資料夾結構看得出層級的地方開啟（`Alt+E`），游標停在一篇有標題與內文的 `.md` 上，讓右欄看得到渲染後的內容 |
| `preview.png` | 預覽欄 ＋ which-key 卡 | 游標停在一篇**有表格**的筆記上（表格是做渲染預覽的主因），然後按 `O` 讓 which-key 卡浮出來 |
| `search.png` | 全文搜尋結果 | `gt` 搜一個會有十幾筆命中的詞，送出後的結果頁：中欄是命中片段、上面有條件 chip |
| `settings.png` | 設定頁 | 設定 → Yazi Explorer → 開啟方式，展開其中一張規則卡（看得到表單與佔位字表） |

## 拍攝建議

- **用預設主題**（或至少是常見的深色主題）。用太客製的主題會讓人以為那是 plugin 的樣子。
- **視窗寬一點**，三欄才不會擠。1600×1000 左右很合適。
- **避開個人資訊**：檔名、內文、書籤路徑都會入鏡。可以先切到一個乾淨的示範 vault，
  或挑沒有敏感內容的資料夾。這是要放上公開 repo 的。
- Windows 用 `Win+Shift+S`，macOS 用 `Cmd+Shift+4` 然後按空白鍵選視窗。

拍好之後直接放進這個資料夾、用上面的檔名即可，README 不用改。
